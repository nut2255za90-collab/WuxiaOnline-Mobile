Wuxia 3D - Android Mobile Prototype (Godot 4)

สิ่งที่มีในโปรเจกต์
- ฉาก 3D หุบเขาไผ่ พื้นหญ้า ทางเดินหิน
- ประตูวัดจีนโบราณ, ต้นไผ่, เสาโคมไฟ
- ตัวละครจอมยุทธ์และศัตรูแบบ low-poly สร้างจาก Mesh พื้นฐานของ Godot
- กล้องมุมสูง, จอยสติ๊กสัมผัสฝั่งซ้าย, ปุ่มโจมตีและวิชา
- HP, MP, EXP และเลเวลแบบ prototype

หมายเหตุสำคัญ
- โมเดลทั้งหมดในเวอร์ชันนี้เป็น low-poly ที่สร้างจาก primitive meshes ภายใน Godot ไม่ใช่ไฟล์ตัวละคร FBX/GLB จากเกมต้นฉบับ
- เป็นเกมทดลองเล่นคนเดียว ยังไม่ใช่ MMORPG ออนไลน์เต็มรูปแบบ
- ZIP นี้เป็นโปรเจกต์ Godot ไม่ใช่ APK ที่คอมไพล์แล้ว

วิธีเปิดบน Android
1. แตก ZIP ลงในโฟลเดอร์
2. เปิด Godot Android Editor
3. Import โปรเจกต์โดยเลือก project.godot
4. เปิด Main.tscn แล้วกด Run
5. ลากนิ้วบนครึ่งซ้ายของหน้าจอเพื่อเดิน และแตะปุ่มด้านขวาเพื่อโจมตี


อัปเดตแก้ไข 2026-10-29
- เพิ่มท้องฟ้า Procedural Sky แทนพื้นหลังสีเรียบ
- เปิดเงาจาก DirectionalLight3D และจำกัดระยะเงาให้เหมาะกับฉากมือถือ
- ยังคงใช้ GL Compatibility เพื่อความเข้ากันได้กับ Android

ข้อควรทราบ: ยังไม่ได้ทดสอบเปิดโปรเจกต์ด้วยตัวรัน Godot ในสภาพแวดล้อมนี้
จึงควรเปิดใน Godot 4 แล้วกด Run เพื่อตรวจสอบ หากมี error ให้ส่งภาพข้อความ error มา
